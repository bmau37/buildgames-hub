Build games with ChatGPT & Codex

ChatGPT for design & code

Use ChatGPT to brainstorm mechanics, write scripts and debug error messages; Canvas lets you edit and preview code side by side.

Codex for repositories

OpenAI Codex is a coding agent that can work on tasks in your repository — implementing features, fixing bugs and proposing changes for review. It is included across ChatGPT plans, with limited access on the free tier.

Prototype in HTML5 first

A single HTML file with canvas is the fastest loop: generate, open in a browser, tweak.

Keep a design doc

Paste a short design doc at the start of new sessions so the model keeps context.

Review everything

Run and read the code; AI output can contain bugs or outdated APIs.
