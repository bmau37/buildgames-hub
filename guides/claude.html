Build games with Claude

Chat + Artifacts

In the Claude app, ask for a small browser game (e.g. 'a single-file HTML canvas Snake game') and Claude can render it as a live Artifact you can play and iterate on.

Claude Code for real projects

Claude Code runs in your terminal, reads your project, edits multiple files and runs commands — useful for Godot, Phaser or Unity projects under version control. It requires a paid Claude plan (Pro and up) or API credits.

Iterate in small steps

Ask for one feature at a time, playtest, then describe what felt wrong. Keep the game in git so you can roll back.

Ask for explanations

Have Claude explain generated code so you can maintain it yourself.

Check your assets

AI can write code quickly; art, music and fonts still need clear licenses before you ship.
