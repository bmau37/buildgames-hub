Glossary

32 game-making words, explained simply.

No jargon left behind.

Asset
Any piece of content in a game: images, sounds, music, 3D models, fonts.
CC BY
A Creative Commons license: free to use if you credit the creator.
CC BY-NC
Like CC BY but non-commercial: you can’t use it in something you sell.
CC0
A public-domain style license: use the asset for anything, no credit needed.
Collision
When two objects touch; engines detect it so you can react (lose a life, pick up a coin).
Core loop
The main thing the player does over and over, like jump–collect–avoid.
Event / signal
A message that something happened (button pressed, enemy hit) that code can react to.
Export / build
Turning your project into something others can play (a web page, an app, an .exe).
Frame rate (FPS)
How many times per second the screen updates. 60 is common.
Freemium
Free to start, with paid upgrades.
Game engine
Software that handles drawing, physics, input and sound so you can focus on your game (e.g. Godot, Unity).
Game jam
An event where people make a game in a short time, often around a theme.
Game loop
The cycle every game repeats: read input, update the world, draw the screen — many times per second.
glTF
A common open file format for 3D models, supported by Blender and Godot.
Hitbox
The invisible shape used to check collisions, often simpler than the art.
Itch.io
A popular site for publishing indie and small games, including free web games.
Low poly
A 3D style with few polygons — simple, fast and beginner-friendly.
MVP
Minimum viable product: the smallest version you could actually release.
Obby
Roblox slang for an obstacle course game.
Open source
Software whose code is public and free to use, change and share under its license.
Physics
Simulated gravity, bouncing and pushing.
Pixel art
Art drawn pixel by pixel at small sizes, scaled up for a retro look.
Playtest
Watching someone else play your game to find what’s confusing or broken.
Prompt
The instructions you type to an AI assistant.
Prototype
A quick, rough version made to test if an idea is fun.
Scene / level
One screen or area of a game, with its objects.
Script
Code attached to an object that tells it how to behave.
Single-file HTML game
A whole game in one .html file that runs in any browser.
Sprite
A 2D image used for a character or object, often with several frames for animation.
Tileset / tilemap
A sheet of small square images (tiles) you arrange on a grid to build levels.
Variable
A named value the game remembers, like score or lives.
Vibe coding
Making software by describing what you want to an AI assistant and refining its output.
