Case study · built with Claude

Junktris

Junktris is a junk-hauling twist on falling-block puzzles: you load real-world junk — mattresses, recliners, dryers, microwaves, a rare oversized shed — into a truck, balancing how tightly you pack against the truck's axle weight limit. It was built with Claude as a single self-contained HTML file and iterated to version 60.

Live — playable on the web; Android build in Google Play prep
