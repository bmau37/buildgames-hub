From vibe-coded to Steam

Intermediate · 5 steps

  1. Prototype with an AI agent

    Describe the core loop and let an agent scaffold a playable HTML5 or Godot prototype.

    Claude Code OpenAI Codex Cursor

  2. Playtest on the web

    Host jam builds for friends to try.

    GitHub Pages itch.io

  3. Move to a real engine

    Rebuild or port into an engine with export targets and proper tooling.

    Godot Engine Unity

  4. Replace placeholder assets

    Swap AI placeholders for consistent art and audio; check licenses.

    Aseprite Blender FMOD

  5. Publish

    Pay the US$100 Steam Direct fee and set up your store page early to gather wishlists.

    Steamworks
